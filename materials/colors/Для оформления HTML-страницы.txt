Для оформления HTML-страницы онлайн-курса на основе выбранной палитры (насыщенный синий #3D78E3 и его оттенки) мы применим принципы современного веб-дизайна: светлый интерфейс с глубокими контрастными акцентами и мягкими пастельными фонами для интерактивных элементов. Чтобы карточки «висели в воздухе», мы добавим деликатную размытую тень.
Ниже приведена полная спецификация элементов экрана с их свойствами и точными HEX-кодами цветов.

🎨 Карта цветов для HTML (CSS переменные)

css
:root {
  --primary-blue: #3D78E3;       /* Основной синий: кнопки, фокус, активные элементы */
  --dark-blue: #2B5CB5;          /* Темно-синий: важные заголовки, текст в плашках */
  --light-blue-bg: #F0F5FE;      /* Пастельный синий: фон для блоков внимания, цитат, квизов */
  --border-blue: #D2E1FC;        /* Цвет рамок: границы нейтральных блоков */
  
  --text-main: #1E293B;          /* Основной текст: не чистый черный, а мягкий темно-серый */
  --text-muted: #64748B;         /* Приглушенный текст: подписи, неактивные пункты меню */
  
  --bg-page: #F8FAFC;            /* Фон самой страницы (светло-серый, чтобы карточки выделялись) */
  --bg-card: #FFFFFF;            /* Фон карточек (чистый белый) */
  
  --success-green: #10B981;      /* Зеленый акцент: правильный ответ */
  --success-bg: #ECFDF5;         /* Фон правильного ответа */
  
  --shadow: 0 4px 6px -1px rgba(0, 0, 0, 0.05), 0 2px 4px -1px rgba(0, 0, 0, 0.03); /* Эффект "в воздухе" */
}
Используйте код с осторожностью.

📋 Спецификация элементов экрана


1. Основное пространство и карточки

• Фон всей страницы (<body>)
	• Свойства: background-color
	• Цвет: #F8FAFC (Очень светлый серый с каплей синего, создает контраст для белых плашек).
• Контентная карточка (Квиз / Глава) — "Висит в воздухе"
	• Свойства: background-color, border-radius, box-shadow
	• Цвет: Фон — #FFFFFF, Тень — rgba(0, 0, 0, 0.05) (Мягкая, еле заметная тень, убирает ощущение плоского листа).
	• Радиус скругления: 12px

2. Текст и заголовки

• Основной текст статьи / вопросов
	• Свойства: color, font-weight: 400
	• Цвет: #1E293B (Угольно-серый. Он воспринимается глазом гораздо легче и лаконичнее, чем абсолютно черный #000000).
• Главные заголовки (Название курса, Главные темы)
	• Свойства: color, font-weight: 700
	• Цвет: #2B5CB5 (Глубокий темно-синий для строгости и авторитетности интерфейса).

3. Интерактивные элементы и меню (Боковая панель)

• Активный пункт меню (Текущая лекция)
	• Свойства: color, background-color
	• Цвет: Текст — #3D78E3, Фон плашки — #F0F5FE (Повторяет логику Jira-панели).
• Неактивные пункты меню
	• Свойства: color
	• Цвет: #64748B (Приглушенный серый, уходит на второй план).

4. Блок цитаты / Важное примечание (Аналог Info Panel в Jira)

• Плашка акцента текста
	• Свойства: background-color, border-left
	• Цвет: Фон — #F0F5FE, Левая акцентная граница — 4px solid #3D78E3.

5. Квиз (Варианты ответов)

• Обычный вариант ответа (До клика)
	• Свойства: background-color, border, color
	• Цвет: Фон — #FFFFFF, Граница — 1px solid #E2E8F0, Текст — #1E293B.
• Выбранный правильный вариант ответа
	• Свойства: background-color, border, color
	• Цвет: Фон — #ECFDF5 (Нежно-зеленый), Граница — 2px solid #10B981, Текст и иконка галочки — #047857 (Темно-зеленый для читаемости).
• Пояснение к правильному ответу (Блок снизу)
	• Свойства: background-color, border
	• Цвет: Фон — #ECFDF5, Граница — 1px solid #A7F3D0.

💻 Пример реализации на чистом HTML/CSS

Вы можете скопировать этот код в файл index.html, чтобы вживую увидеть, как эти цвета взаимодействуют на странице.
html
<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <title>Пример страницы курса</title>
    <style>
        body {
            font-family: -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif;
            background-color: #F8FAFC;
            color: #1E293B;
            margin: 0;
            padding: 40px;
            display: flex;
            justify-content: center;
        }
        .container {
            max-width: 700px;
            width: 100%;
        }
        h1 {
            color: #2B5CB5;
            font-size: 24px;
            margin-bottom: 8px;
        }
        .subtitle {
            color: #64748B;
            font-size: 14px;
            margin-bottom: 24px;
        }
        /* Плашка, висящая в воздухе */
        .card {
            background-color: #FFFFFF;
            border-radius: 12px;
            padding: 24px;
            box-shadow: 0 4px 6px -1px rgba(0, 0, 0, 0.05), 0 2px 4px -1px rgba(0, 0, 0, 0.03);
            border: 1px solid #E2E8F0;
            margin-bottom: 20px;
        }
        /* Блок цитаты / Важного примечания */
        .info-note {
            background-color: #F0F5FE;
            border-left: 4px solid #3D78E3;
            padding: 16px;
            border-radius: 0 8px 8px 0;
            margin: 16px 0;
            color: #1E293B;
        }
        /* Элементы Квиза */
        .quiz-title {
            font-weight: bold;
            font-size: 16px;
            margin-bottom: 16px;
        }
        .option {
            border: 1px solid #E2E8F0;
            border-radius: 8px;
            padding: 14px 16px;
            margin-bottom: 12px;
            cursor: pointer;
            transition: all 0.2s ease;
            background-color: #FFFFFF;
        }
        .option:hover {
            border-color: #3D78E3;
            background-color: #F0F5FE;
        }
        /* Правильный ответ */
        .option.correct {
            background-color: #ECFDF5;
            border: 2px solid #10B981;
            color: #047857;
            font-weight: 500;
        }
        /* Блок пояснения */
        .feedback {
            background-color: #ECFDF5;
            border: 1px solid #A7F3D0;
            border-radius: 8px;
            padding: 16px;
            margin-top: 16px;
            font-size: 14px;
        }
        .feedback-title {
            color: #047857;
            font-weight: bold;
            margin-bottom: 6px;
        }
    </style>
</head>
<body>
